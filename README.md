# Downloadverse
A download manager that let download files from internet including torrents magnets and more.
It can download pastebin links so you don't have to download every single file manually from the link.

This is my first rep so the readme will be very poor i don't want to let an ai write a readme for me.

I used Deepseek 4.1 flash and some Opus 5.5 and gpt luna 6. 
Written in python, my goal is to let the manager download files that are slowed by countdown for free users and redirect of ads and other things that don't let you download instantly what you want.
